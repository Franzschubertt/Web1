# Web1

Repositório destinado ao armazenamento e à organização de atividades acadêmicas desenvolvidas durante os estudos de desenvolvimento web.

Objetivo

Registrar a evolução do aprendizado por meio de aulas, exercícios, avaliações e atividades práticas.

mantendo os arquivos organizados e facilitando a consulta e a revisão dos conteúdos estudados.

Estrutura do Repositório

Aulas/ — Arquivos e exemplos desenvolvidos durante as aulas.

Exercicios/ — Exercícios realizados para praticar e fixar os conteúdos estudados.

Provas/ — Arquivos e atividades relacionados às avaliações acadêmicas.

Praticas/ — Atividades práticas desenvolvidas para aplicar os conhecimentos adquiridos.
